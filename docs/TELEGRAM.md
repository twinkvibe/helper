# Telegram-бот

Бот дублирует веб-хелпер: задачи, быстрые записи, досье, вопросы ИИ — плюс
уведомления о входах, ошибках и недоступности ИИ.

## Как устроено

- Edge Function `telegram` принимает webhook от Telegram (`POST`).
  Подлинность проверяется заголовком `X-Telegram-Bot-Api-Secret-Token`
  (секрет `WEBHOOK_SECRET`); платформенная проверка JWT для функции выключена
  (`verify_jwt = false` в `supabase/config.toml`), иначе Telegram не пройдёт.
- Привязка: один пользователь — один чат. Код из раздела Аккаунт → боту
  `/start 123456`. Код одноразовый, живёт 10 минут, хранится только sha256-хэш.
- Все операции бота идут через `service_role`, но каждая сверяет
  `user_id` строки с владельцем чата. Чужие задачи/записи недоступны даже при
  подборе ID.
- История диалога с ИИ — таблица `telegram_history`, последние 30 сообщений
  на чат, остальное чистится.

## Команды и кнопки

| Ввод | Что делает |
| --- | --- |
| `/tasks` | открытые задачи + инлайн-кнопки ✓ (нажал — выполнена, список обновился) |
| `/add текст` | быстрая задача во Входящие |
| `/ask текст` / просто текст | вопрос ИИ, помнит контекст беседы; ИИ может задавать встречные вопросы |
| `/dossier имя` | карточка человека: статусы, факты, 3 последних события |
| `/clear` | очистить контекст беседы |
| `/cancel` | отменить ожидание ответа |
| `/unlink` | отвязать чат |
| `/help` | справка |
| фото с подписью | запись в досье с фото (подпись → заголовок и текст) |

ИИ текст-онли: фото в модель не уходят, только сохраняются в `dossier-media`.
Видео/документы из чата пока не принимаются — бот так и отвечает.

## Опросники

Когда агенту нужна развилка, он вызывает инструмент `ask_user`: вопрос уходит
инлайн-кнопками (варианты заодно нумеруются в тексте сообщения, но ответить
можно только кнопкой) плюс кнопка «Свой вариант» (ждёт свободный текст).
Цикл приостанавливается, состояние ждёт в `telegram_pending`, после ответа
цикл продолжается с того же места. Лимит — 2 уточнения на одно сообщение,
дальше агент решает сам. Любая команда ожидание отменяет.

## Форматирование и UX

Ответы идут с `parse_mode: HTML`: Markdown модели конвертируется
(`markdownToTgHtml` — жирный, курсив, зачёркнутый, код, ссылки, заголовки),
несбалансированная разметка остаётся текстом. Если Telegram всё же отверг
разметку — сообщение автоматически пересылается plain text. Перед долгим
ответом ИИ бот показывает «печатает…». `/clear` чистит историю беседы.

## Уведомления (в привязанный чат)

- 🔑 вход в helper (имя, время) — сайт шлёт `notify:login` после входа;
- ❗ клиентская ошибка — `notify:error`, троттлинг максимум раз в 5 минут;
- ⚠️ все ИИ-провайдеры недоступны — сервер сам, после перебора цепочки.

## Запуск с нуля

1. Примени `supabase/migrations/20260926_telegram.sql` (после досье-миграций).
2. Задеплой функции: `supabase functions deploy account telegram --project-ref <ref>`.
3. Секреты функции (Supabase → Edge Functions → Secrets или `supabase secrets set`):
   `AI_CHAIN`, `BOT_TOKEN`, `WEBHOOK_SECRET`. Опционально legacy `AI_API_KEY` /
   `AI_BASE_URL` / `AI_MODEL` — встанут в конец цепочки.
4. Создай бота через @BotFather, забери токен → `BOT_TOKEN`.
5. Поставь webhook одной командой:
   ```sh
   curl -X POST "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
     -H "Content-Type: application/json" \
     -d '{"url":"https://<project>.supabase.co/functions/v1/telegram","secret_token":"<WEBHOOK_SECRET>"}'
   ```
6. На сайте: Аккаунт → Telegram → Получить код → боту `/start 123456`.

## Формат AI_CHAIN

```json
{"providers":[
  {"name":"agentrouter","baseUrl":"https://agentrouter.org/v1","apiKey":"...","models":["deepseek-v4-flash"]},
  {"name":"groq","baseUrl":"https://api.groq.com/openai/v1","apiKey":"...","models":["openai/gpt-oss-120b","qwen/qwen3.8-27b"]}
]}
```

Перебор по порядку провайдер→модели. 401/403 — пропускает весь провайдер
(ключ мёртв). Пустой ответ/ошибка — следующая попытка. Всё упало — исключение
`AI_UNAVAILABLE`, веб-сторона шлёт уведомление в Telegram.

Проверено живьём 2026-10-10: на Groq отвечают `openai/gpt-oss-120b` и
`qwen/qwen3.8-27b`; `llama-3.3-70b-versatile` снята, `minimaxai/minimax-m2.7`
не существует. Путь AgentRouter — `https://agentrouter.org/v1/chat/completions`,
выданный ключ им отвергнут (`unauthorized client`) — разбираться с поддержкой.
